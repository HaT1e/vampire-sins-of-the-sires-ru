# Мод «Все достижения»

Добавляет в главное меню игры **Vampire: The Masquerade — Sins of the Sires** пункт
**«Открыть все достижения.»**. После подтверждения открываются все 15 достижений
(включая скрытые), начисляются их 750 очков и результат сохраняется в браузере
или приложении так же, как при обычном получении достижений.

Мод сделан для русской версии перевода (игра 76502) и содержит готовый
переведённый `ui.js`. Скрипт установки добавляет только три небольших фрагмента
и не трогает сцены, сохранения и текст игры.

## Установка

### Способ 1: заменить `ui.js` (проще всего)

1. Сделайте резервную копию файла `deploy/ui.js` из папки с игрой.
2. Скопируйте `ui.js` из этой папки в `deploy/` с заменой.
3. Запустите игру и откройте **Меню** → **«Открыть все достижения.»**.

### Способ 2: установить автоматически

Нужен Node.js. Из этой папки выполните:

```bash
node install.js "C:\путь\к\игре\deploy"
```

Можно указать и сам файл:

```bash
node install.js "C:\путь\к\игре\deploy\ui.js"
```

Скрипт создаст резервную копию `ui.js.bak` рядом с файлом и добавит мод.
Если мод уже установлен, скрипт ничего не изменит. Установщик рассчитан
на русскую `ui.js` из перевода: он ищет русские подписи меню.

### Способ 3: вручную

В `deploy/ui.js` найдите блок в функции `showMenu`:

```js
if (nav.achievementList.length) options.push(
  { name: "Посмотреть достижения.", group: "choice", achievements: true }
);
```

Замените его на:

```js
if (nav.achievementList.length) options.push(
  { name: "Посмотреть достижения.", group: "choice", achievements: true },
  { name: "Открыть все достижения.", group: "choice", unlockAllAchievements: true }
);
```

В той же функции, после ветки `option.achievements`, добавьте:

```js
} else if (option.unlockAllAchievements) {
  return unlockAllAchievements();
```

И перед функцией `function achieve(name, title, description) {` добавьте:

```js
function unlockAllAchievements() {
  asyncConfirm("Открыть все достижения? Это действие нельзя отменить.", function(result) {
    if (!result) return;
    for (var i = 0; i < nav.achievementList.length; i++) {
      nav.achieved[nav.achievementList[i]] = true;
    }
    checkAchievements(function() {
      if (initStore()) window.store.set("achieved", toJson(nav.achieved));
      showAchievements();
    });
  });
}
```

## Возврат к обычной игре

Замените `deploy/ui.js` обратно резервной копией (`ui.js.bak` или вашей копией
до установки). Достижения, уже записанные в сохранение, останутся открытыми —
это стандартное поведение игры.

## Примечания

- Мод не выдаёт достижения «навсегда» для чужого аккаунта: он пишет их в
  локальное хранилище игры на вашем устройстве.
- В Steam-версии при открытии достижений также вызывается штатная регистрация
  достижений Steam, если она доступна в текущем окружении.
- После нажатия «Открыть все достижения.» сразу открывается экран достижений:
  можно убедиться, что всё открыто (15 из 15, 750 очков).
- Мод не изменяет сюжет, сохранения персонажа и файлы сцен.
