# Стайлгайд русского перевода

## Игра и рамка

**Vampire: The Masquerade — Sins of the Sires** (Choice of Games, 2022).
Перевод — фанатский оверлей; оригинальная игра не входит в релиз.
Рабочий язык — русский литературный, с сохранением нуарной интонации,
иронии и телесности оригинала.

## Голос и время

- Повествование — **второе лицо, настоящее время**: «Вы идёте по улице»,
  «Ночь пахнет дождём». Прошедшее — только для воспоминаний.
- Внутренняя речь игрока — первое лицо в вариантах выбора («Подхожу к
  двери»), без гендерно зависимых причастий и прошедшего времени.
- Обращение рассказчика к игроку — **«вы»** (строчная).
- Реплики NPC игроку — **«ты»** по умолчанию: вампирское общество
  неофициально, персонажи близки, фамильярны или агрессивны. «Вы» — только
  если персонаж сознательно переходит на официальную дистанцию
  (двор, Принц, публичная сцена); такие переходы фиксируются в заметках.
- Между NPC — «ты», кроме официального двора.
- Тон: сдержанный нуар, короткие фразы, без канцелярита и «книжных»
  конструкций. Ругательства — по силе оригинала, без усиления.

## Оформление

- Кавычки: внешние «ёлочки», внутренние „лапки“.
- Тире в диалогах и вставках: длинное тире с пробелами (—).
- Многоточие: … (один символ), не три точки.
- Буква **ё** используется последовательно.
- Курсив и полужирный — только там, где в оригинале `[i]`/`[b]`.
- Числа: «5 достижений», «Достижений: 5»; даты — «24 июля 2019 года».
- Названия глав — как в глоссарии.

## Термины

Канон V5 — см. `docs/glossary.json`. Ключевое:

- Кровь, Голод, Зверь, Человечность — с заглавной, когда это игровые
  категории; «пакет крови», «кровь» — строчная в бытовом смысле.
- Сородичи, Камарилья, Анархи, Маскарад, Принц, Сенешаль, Шериф, Скиф,
  Примоген, Примогены — с заглавной.
- Объятие (ритуал) — с заглавной; «обратить» — глагол.
- чадо, сир, каитифф, гуль, витэ, диаблерия — строчные.
- Слабокровный / слабокровные — по контексту.
- Дисциплины — с заглавной: Анимализм, Ясновидение и т. д.
- «Маскарад» не переводится как «маскарад» в бытовом смысле.

## Переменные и грамматика

### Принцип

Переводится только то, что видит игрок. Код, имена переменных, метки,
значения, участвующие только в условиях, остаются английскими.

### Строковые значения

- Если значение выводится (`${var}`) — переводим, включая `*temp`,
  `*create`, `*set`. Например, `person`: man/woman/person →
  мужчина/женщина/человек; `child`: son/daughter/child → сын/дочь/ребёнок.
- Если значение участвует только в `*if`/`@{}` как код — не переводим
  (`first_discipline`, `current_page`, числовые ID).
- Если значение и показывается, и сравнивается — переводим **везде** и
  прогоняем `audit-values.js` до нуля MIXED.
- Пустая строка — валидное значение, не «переводим».

### Местоимения игрока и NPC

- Стандартные выборы: he/him → он/его; she/her → она/её;
  they/them → они/их. Значения `e`, `eir`, `em`, `eirs`, `emself`
  переводятся; `emself` — «себя» для всех.
- Ввод своих местоимений: подсказки переведены, игрок вводит русские
  формы. `eirs` в русском совпадает с `eir` — это нормально.
- `plural` остаётся булевым; варианты `@{plural ...|...}` переводятся
  парами («говорят|говорит»).
- Род: `gender` 1=женский, 2=мужской, 3=небинарный. Селекторы
  `@{(gender = 1) ...}` сохраняют селектор, варианты переводятся.
- **Не вкладывайте `@{}` в `@{}`.** Если для русского нужны три формы,
  перефразируйте строку или используйте `@{gender ...}` с тремя
  вариантами, где это допустимо.
- Прошедшее время, зависящее от рода, перефразируется: «Вы пришли» —
  нейтрально; «${e} пришёл» — через `@{gender пришла|пришёл|пришли}`
  только если gender гарантированно совпадает с формой; иначе строка
  переписывается в настоящем времени.
- `${person}`, `${t_person}` и подобные существительные вставляются так,
  чтобы прилагательные не согласовывались с переменной: «${t_person}
  преклонных лет», «человек по имени…».

### Интерполяция

- `${...}`, `$!{...}`, `$!!{...}` — имя/выражение не трогать; литеральный
  текст внутри — можно.
- `@{селектор a|b}` — селектор не трогать; варианты переводить, число
  вариантов можно менять осознанно.
- `[i]`, `[b]` — сохранять.
- `*comment` и `*bug` — не переводить.

### Команды

`*choice`, `*if`, `*set`, `*goto`, `*label`, `*finish`, `*image`,
`*text_image`, `*stat_chart`, `*achievement` и все прочие команды
сохраняются дословно. Подписи после `*finish`, `*page_break`,
`*text_image`, alt-текст `*image` — переводятся.

## Варианты выбора

- Один вариант = одна строка, `#` сохраняется.
- Варианты короткие, без спойлеров, понятные без английского.
- Порядок и количество вариантов не меняются.
- Первое лицо, настоящее время; без гендерных причастий.
- Не добавлять шутки и пояснения, которых нет в оригинале.

## UI

- Кнопки и меню — короткие, в одно слово, если возможно.
- Не переводить ID, ключи, CSS-классы, URL, имена функций.
- «Сохранений: N» вместо склейки числа и слова.
- После правок JS — `node --check`.

## Изображения

- Заголовки глав и разделов — по глоссарию.
- Размер и стиль сохраняются; текст без обрезки.
- Содержимое проверяется глазами: имя файла не гарантирует текст.
